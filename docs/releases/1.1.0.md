# Better SignalRGB Screen Capture 1.1.0

This release overhauls capture, canvas editing and streaming, with fixes for recurring crashes and resolution-related encoding failures.

## Highlights

- **High-quality web output:** optional 800 × 600 composition and more detailed capture/preview. Source placement, crops and rotations survive mode changes exactly. SignalRGB keeps its low-resolution output.
- **Clean browser effect page:** `/` and `/canvas` show only the raw composite, fill the viewport and reconnect after interruption. Suitable for consumers that accept a web page as an effect.
- **Canvas improvements:** rebuilt crop and gesture handling, reliable corner resize at canvas edges, rotation knobs outside the canvas, snapping, alignment guides, layout locks and consistent undo/redo.
- **Wallpaper Engine source:** captures the actual rendered wallpaper surface while other windows cover it, including web, scene and video wallpapers. Wallpaper Engine's own pause/stop rules still control whether its animation advances.
- **Independent website capture:** continues without the editor being visible. Local `file:///` HTML, images and browser-supported videos are accepted; local videos play muted in a loop.
- **Scenes, setup and diagnostics:** named profiles with import/export, guided SignalRGB effect installation/update and render confirmation, plus source errors, frame rates, drops and encoder diagnostics.
- **Stability and performance:** bounded frame queues, shared decoding/composition, safer native buffer ownership and fixes for three diagnosed WinUI crashes. Automatic recording defaults to enabled while respecting an explicitly saved disabled preference.

## Installation and upgrade

1. Download the archive for your Windows architecture and extract **all** files into a new folder.
2. Exit the previous instance from its tray menu, then run `Better-SignalRGB-Screen-Capture.exe`.
3. Update the matching bundled HTML effect through **Settings → SignalRGB setup**. The same effect is also available as a separate download.
4. Existing settings and source layouts remain in the local application-data folder. HQ is optional and off by default; enable **HQ 800 × 600** in the canvas toolbar.

The portable archives include .NET and Windows App SDK runtimes. Native capture requires the [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) matching the application's architecture. Website/local media capture requires the [Microsoft Edge WebView2 Runtime](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution). Windows N/KN editions need their Media Feature Pack for native media capture. SignalRGB is needed only for the SignalRGB output; Wallpaper Engine must be running to capture its rendered surface. `SHA256SUMS.txt` lists the download hashes.

## Validation

The overhaul passed 2,034 geometry/model/persistence/XAML assertions, 188 view-model assertions and 156 compositor/HTTP/HTTPS assertions. Native capture tests exercised the available Windows 11 x64 machine, and Chromium pixel comparisons covered transformed sources, crops, mirrors, filters, live HQ switching and reconnection. x86 and ARM64 are additional builds with less hardware coverage; ARM64 cannot be executed on the x64 validation machine. Windows 10 is not covered by the current hardware validation. No universal CPU/GPU or latency percentage is claimed; results depend on the selected sources, drivers and devices.
